简历工坊 · 20款可填写网页模板
============================

打开方式
解压完整文件夹后，在 Edge、Chrome、Firefox 或 Safari 中打开 index.html。
无需安装依赖、注册账号或运行服务器。所有样式、脚本和素材均在本地目录中。

使用流程
1. 在模板库查看20款真实HTML排版缩略图，可按风格筛选、搜索或收藏。
2. 点击“使用此模板”进入编辑器，在左侧填写基本资料与经历。
3. 教育、工作/实习、项目经历都支持增加、删除和上下排序。
4. 技能、语言、证书、奖项和个人补充内容按需填写；空条目自动隐藏。
5. 在预览上方切换模板，共用同一份资料，不必重新输入。
6. “导出简历”可下载PNG、JPG、PDF、JSON备份或独立HTML简历，也可以导入本站JSON备份。
7. 点击“打印 / 存为PDF”，在浏览器中选择A4、关闭页眉页脚，按需要开启背景图形。

资料保存
- 填写内容和收藏会自动保存在当前浏览器的 localStorage 中。
- 数据不会发送到模板网站或其他后端服务。
- 清理浏览器数据、更换浏览器或设备后，需要导入原先的JSON备份。
- 浏览器不允许本地文件保存时，仍可编辑和下载备份；请关注保存状态提示。
- 示例人物、学校、公司、经历均为虚构，示例邮箱使用 example.com。
- 照片选填，支持JPG/PNG/WebP，单张不超过6MB；读入后缩小以方便本机保存。
- 网页不代写经历，填入示例后请按自己的实际情况修改再使用。

打印和导出
- 页面预览和浏览器打印使用真实可选中文字；直接下载的PDF采用高清图片式排版。
- PNG导出整份简历的高清长图；JPG导出白色底的压缩长图，包含照片及模板色彩。
- 直接下载PDF会逐页生成A4图像，优先避开文字行、照片和标题进行分页。
- 需要可选择文字的PDF时，请使用“打印 / 存为PDF”，再在浏览器中选择另存为PDF。
- 默认图片为2倍像素；特别长的图片会调整分辨率，超过画布限制时会提示改用PDF。
- 极长或两栏文字过密时，可使用浏览器打印，避免强行切开文字。
- 文字较多时，预览会增高，打印自然延展为多页，正文不因固定页高被裁掉。
- 不同模板的信息排列顺序不同，打印后的分页也可能不同。
- 独立HTML下载内置简历样式，无需同时携带其他文件即可打开或打印。
- JSON用于继续编辑，HTML用于独立阅读和打印；HTML不是可重新导入的资料备份。
- 招聘平台的解析方式各不相同，本项目不承诺特定招聘系统的识别效果。

文件结构
index.html  网页结构、表单入口、说明弹窗
styles.css  唯一CSS：前半部分为20套简历排版，后半部分为网页界面和打印规则
app.js      唯一JS：模板引擎、填写逻辑、图像/PDF库与全部导入导出功能
THIRD_PARTY_LICENSES.txt  内置图像及PDF导出库的开源许可证
assets/     本地SVG站点图标与鼠标

CSS与JS均已合并，各保留一个文件，不需要构建步骤。
修改简历排版样式后，请同步更新app.js第二节中的RESUME_EXPORT_CSS，
使独立HTML下载与页面预览一致。常规填写无需修改任何代码。
